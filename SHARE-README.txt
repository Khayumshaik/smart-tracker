DietDabba web preview

This is the browser preview export. To share it with friends, upload the contents of this folder to any static web host and send them the generated URL. The app is not publicly hosted yet; the localhost preview only works on your computer.

For local testing from the project folder, run:
  npx expo start --web

This is a web preview, not an installable iOS or Android app. Login and app data are prototype/local-only; no real account service or cloud sync is connected.
